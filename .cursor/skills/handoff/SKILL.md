将当前对话浓缩为交接文档，使全新启动的 Agent 能够接续工作。将文档保存到 `mktemp -t handoff-XXXXXX.md` 生成的路径（写入前先读取该文件）。

在文档中建议下一个会话应使用的技能（如有）。

**不要重复**已在其他产物中记录的内容（PRD、计划、ADR、issue、commit、diff）——用路径或 URL 引用即可。

若用户传入了参数，将其作为下一个会话焦点的描述，并据此调整文档内容。

## 交接文档结构

```markdown
# 交接文档

## 当前状态
简述已完成的工作和当前代码库状态。

## 上下文快照
- 核心决策及其理由（可引用 ADR/commit）
- 已知未解决的问题
- 重要的域语言或约定

## 下一步工作
明确下一个会话需要完成的任务，按优先级排列。

## 建议技能
列出下一个会话应载入的技能（如有）。

## 相关文件/链接
引用 PRD、issue、计划文档等（不复制内容）。
```
